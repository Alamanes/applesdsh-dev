# 备忘录

DSH 右侧边栏里的一本备忘录：一张清单、一个目标簿，和一本由模型替你写的日记。

## 为什么要有它

每天都有很多零碎的念头，清单只记得住结论，日记又懒得写。这里换了个顺序：你只要把今天做了什么说一句，模型把它整理成你的日记；你给自己立下的目标，会在复盘时被翻出来，对着这段时间的日记说清楚你走到哪了、卡在哪里。

清单、目标、日记原本是三件事，放在同一个侧栏里，是因为它们回答的是同一个问题：你在往哪走。

## 它在哪

右侧边栏首页多一个「备忘录」，和「工作区文件」「新建终端」「浏览器」并排。

**清单**是横线分隔的条目：一行标题，需要时补一段备注和一列步骤。双击标题改字，备注里放材料、条件、链接这类长内容。下面的输入框回车即添加。

**目标**是一句话，外加一句可选的衡量标准，时间这类条件直接写进去。卡片下方四个图标：复盘、记一笔进度、完成、删除。复盘会读目标立下以来的全部日记，按你选的口吻写一段点评——毒舌、温柔、机械，或者你自己写一段语气说明。口吻在右上角齿轮里改。

**日记**跟在目标下面，只读。下面的输入框和清单那个一样：写一句，回车。素材先落到本地，模型随即用你的第一人称把它整理成一页；写失败了，日记标题旁会出现一个刷新按钮，素材不会丢。

## 安装

```text
把 https://github.com/Alamanes/dsh-sidebar-memo 装进我的 DSH profile：
1. 在 ~/.dsh/profiles/<profile>/package.json 的 dependencies 里加入
   "dsh-sidebar-memo": "github:Alamanes/dsh-sidebar-memo"
2. 把 "dsh-sidebar-memo" 加进同文件的 dsh.profile.bundles 列表
3. 在 profile 目录执行 pnpm install
4. 重启 DSH
```

## 你的东西在哪

清单、目标、日记和口述素材都在 `~/.dsh/storages/dsh-memo` 下，一份 Markdown、一份 JSON，不联网，没有上传功能。

## 给模型的口子

插件注册了 `memo` 和 `diary` 两个工具。`memo` 管清单，也能读写目标；`diary` 按天读写日记。目标同时出现在工具参数和会话的 Goal 工具里，两者的分工写在工具说明里：Goal 管模型自己手头的事，`memo.goal` 记的是你立下的目标。

# dsh-ui-copy

界面套件的文案组件：空态大标题轮换、输入框空置提示改写，以及预览版徽章隐藏。套件组件，默认全开，插件页停用整行即可。

## 职责

- **大标题轮换**：空态页的大标题按 `<html lang>` 从对应语言的句池中轮换。
- **输入框提示**：输入区的空置提示改为自定文案，随语言切换。
- **预览版徽章**：隐藏大标题旁的预览版徽章，可由配置关闭。

## 配置

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| `hidePreviewBadge` | `true` | 隐藏标题旁的预览版徽章 |

## 实现

宿主半边把这一行的配置以 `window.DSHUI_COPY` 注入页面，并将令牌层写入 `<head>`；文案改写全部在浏览器半边完成，源码在 `src/component.js`，由 `scripts/build.mjs` 拼进 `lib/client.js`。

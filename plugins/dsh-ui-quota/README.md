# 更好的用户菜单（dsh-ui-quota）

左下角用户菜单与设置页「用量」：账户菜单收纳侧栏面板入口，用量抽屉显示月度额度与峰谷倒计时，设置页保留额度卡片与 Token 热力图。

> **必须搭配页面套件 [`dsh-ui-suite`](../dsh-ui-suite) 使用。**
> 本包只负责菜单增强与用量页，菜单的表面与动效、侧栏行样式、`--dshui-*` 令牌层都由套件提供。单独安装本包，界面不完整，菜单也会退回宿主样式。

## 依赖套件的原因

| 套件组件 | 本包用到的部分 |
| --- | --- |
| `dsh-ui-menu` | 菜单的入场动画与层次 |
| `dsh-ui-sidebar` | 侧栏行高度、面板行样式 |
| `dsh-ui-copy` | 菜单层的进入标记 |
| `dsh-ui-identity` | 侧栏左下角的名字与头像（菜单头像行读它） |
| 令牌层 | `--dshui-*` 全部颜色、圆角、间距、动效曲线 |

本包的 `cordis.patch.yml` 只插入自己一行，不重复安装套件。

## 左下角菜单

- **头像行**：头像与登录名，整行缩窄；点击打开菜单。
- **剩余用量**：可展开抽屉，收起时只占一行。
  - 月度额度：剩余百分比与重置日期
  - 峰谷：当前计费时段与距下次切换的倒计时，每秒刷新
  - 显示更多：打开设置并停在用量分区
- **面板入口**：侧栏 `sidebar.panellist` 里的每一项（插件、使用统计、技能中心、记忆，以及以后任何插件新增的入口）自动隐藏并在菜单里生成一行，点击转发回原按钮。
- **设置**：保留宿主入口与 ⌘, 快捷键。
- **意见反馈、退出登录**：隐藏，不渲染占位。

菜单样式在增强时写入：`data-dsh-quota-menu` 标记菜单容器，行统一切成 30px 高、13px 字、16px 图标、8px 圆角、6% 文字的 hover 底色。

## 设置页「用量」

- 排在「通用设置」之后，打开设置时不会被抢焦点。
- 月度额度一张、5 小时与每周并排，底部 53 周 Token 热力图。
- 等数据时显示骨架：空额度卡带进度色带与扫光，热力图先铺满空白格。
- 读数跨挂载缓存，重进设置先画上次结果再后台刷新。

## 数据来源

| 端点 | 数据 | 缓存 |
| --- | --- | --- |
| `/api/cc-quota/report` | 账户、套餐、月度与滚动窗口额度 | 15 秒，失败回落到上次快照 |
| `/api/cc-quota/activity` | 本地会话日志聚合出的每日 Token | 60 秒 |
| `/dsh-ui-copy/peak-valley/holidays.json` | 中国法定节假日日历 | 24 小时 |

额度接口是四路只读 GET（whoami / usage / credits / subscriptions），接口报美元、按 `$1 = 100 Credits` 换算。热力图不碰网络，遍历 `sessionPersistence` 的会话日志按本地日期聚合。节假日从 holiday-cn 抓当年与下一年，抓不到时用内置的 2026 年列表兜底。

## 安装

在 profile 的 `package.json` 里同时装上套件与本包，再把两者都加进 `dsh.profile.bundles`：

```json
{
  "dependencies": {
    "dsh-ui-suite": "file:../dsh-ui-suite",
    "dsh-ui-quota": "file:../dsh-ui-quota"
  }
}
```

```json
{
  "dsh": {
    "profile": {
      "bundles": ["dsh-ui-suite", "dsh-ui-quota"]
    }
  }
}
```

## 已知限制

- **额度数据只适配 Command Code**。换成其他供应商时额度卡没有数据，热力图仍然可用；供应商适配层尚未实现。
- **面板入口收集依赖宿主的类名**（`_panelList`、`_panelRow`）。宿主改版改了结构时，收集会静默失效，侧栏原本的行会重新出现。
- **菜单是 DOM 增强**：宿主升级改了菜单文案或结构，增强会退回原样，不会报错。
- 隐藏了「意见反馈」与「退出登录」，需要它们时把对应文案从隐藏名单里去掉即可。
